## 1. Multi-Viewport Browser QA Audit Baseline

Before modifying any code, the built site (`28` static HTML routes across English and Vietnamese) was rendered and inspected in headless Chromium across `5` viewports (`320 × 760`, `390 × 844`, `768 × 1024`, `900 × 800`, and `1280 × 800`):

- **Zero horizontal overflow (`scrollWidth <= innerWidth`)** across all viewports and locales.
- **Identified UI/UX and IA gaps resolved in G7:**
  1. **Touch target heights (`< 40px`):** `.brand` (`27.5px`), `.desktop-nav a` (`22.5px`), `.lang-links a` (`26px`), `.hint-actions a` (`21px`), `#dismiss-language` (`28px`), `.card-link` (`20px`), and `.contact-address` (`27.5px`) fell below comfortable mobile tap thresholds.
  2. **Tablet grid imbalance (`768px` – `900px`):** `.cards` switched from `3` columns to `2` columns at `@media (max-width: 900px)`, leaving the 3rd card in a 3-item group (`Core web services` and `Selected self-developed work`) stranded on half a row (`50%` width).
  3. **Domain card affordance (`/domains/` & `/vi/domains/`):** static `li.collaboration-name` items shared almost identical border/radius/surface styling with interactive `a.sale-card` links, while the section inquiry link (`a.domain-action.collaboration-inquiry`) used a plain text link instead of a button CTA.
  4. **Mobile navigation hierarchy (`details.mobile-nav`):** `10` links (4 primary sections, 5 service detail sub-pages, 1 contact CTA) were rendered as a single flat list without visual grouping, and active service sub-pages did not receive `aria-current="page"` in the mobile menu.
  5. **Orphan routes (`/collaborate/` & `/vi/collaborate/`):** included in `public/sitemap.xml` and generated at build time, but had `0` inbound `<a href>` links from any page on the website.
  6. **Bottom section CTA contrast (`.section-bottom`):** the closing inquiry button on Home and Services used `.button.ghost` (`background: #fff`) on top of an already light panel (`#F8FAFC`).

## 2. G7 Implementation Across 3 Gated Checkpoints

### Chốt 1 — CSS Touch Targets, Tablet Grid Balance & Domain Affordance
- **`src/styles/global.css`:**
  - Standardized `min-height: 40px` (`42px` on mobile links) with `inline-flex` alignment across `.brand`, `.desktop-nav a`, `.lang-links a`, `.hint-actions a`, `#dismiss-language`, `.card-link`, and `.contact-address`.
  - Added `grid-column: span 2` for `.cards:not(.cards-two) > .card:nth-child(3):last-child` inside `@media (max-width: 900px)` and reset to `grid-column: auto` inside `@media (max-width: 680px)`.
- **`src/components/DomainCatalog.astro`:**
  - Styled `.collaboration-name` with a subtle dashed border (`1px dashed var(--line-strong)`), soft surface (`rgba(255,255,255,.72)`), and an accent status dot (`::before`) to distinguish static domain labels from clickable `.sale-card` links.
  - Upgraded `.domain-action.collaboration-inquiry` into a dark primary CTA button matching `.button`.

### Chốt 2 — Mobile Navigation Hierarchy, `aria-current`, Internal Link to `/collaborate/` & Bottom CTA
- **`src/layouts/Base.astro` & `src/pages/404.astro`:**
  - Added `.mobile-sublink` and `.mobile-sublink-first` classes to service sub-items inside `.mobile-links`, indenting them with a vertical guide rail (`border-left: 2px solid var(--line-strong)`).
  - Set `aria-current="page"` on the active service detail link in `.mobile-links` and `aria-current="true"` on the parent `Services` / `Dịch vụ` link when viewing a service detail page.
  - Added an open-state style for `details.mobile-nav[open] summary` (`border-color: var(--accent)`, `color: var(--accent)`).
  - Added contextual links (`Read collaboration guidelines ↗` / `Xem nguyên tắc đề xuất hợp tác ↗`) pointing to `/collaborate/` and `/vi/collaborate/` on the `About` and `Domains` pages.
  - Upgraded the `.section-bottom` CTA button from `.button.ghost` to `.button`.

### Chốt 3 — Automated Static QA Regression Gate (`scripts/g5-qa.mjs`)
- Extended `scripts/g5-qa.mjs` to automatically fail CI if:
  - Any generated route in `routes` or `drafts` (`noindex` utility pages) has `0` inbound `<a href>` links across the site (`inboundAnchorLinks` check).
  - Any service detail page is missing `aria-current="true"` on the parent Services link or `aria-current="page"` on the active service sub-link inside `.mobile-links`.
  - Key UI/UX CSS regression markers (`.card-link` minimum touch height, `.mobile-sublink` hierarchy, `.collaboration-name::before` indicator) are missing from the built output.

## 3. G8 Legal Notice Finalization (`Privacy` & `Terms`)

- **`src/lib/copy.ts`:**
  - Removed the `· draft` / `· bản nháp` eyebrow suffixes on `/privacy/`, `/vi/privacy/`, `/terms/`, and `/vi/terms/`.
  - Removed provisional `"under review"` / `"đang được rà soát"` phrasing while preserving the factual descriptions of static-site operation, email handling, and contract disclaimers.
  - Kept `<meta name="robots" content="noindex,follow" />` on `/privacy/` and `/terms/` (both EN and VI) so utility legal notices remain accessible via the footer without competing with core service and portfolio pages in search indexation.
- **`scripts/g5-qa.mjs`:**
  - Added an explicit check ensuring neither `· draft` nor `· bản nháp` appears in built `privacy` or `terms` HTML files.
